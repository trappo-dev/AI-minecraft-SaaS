TrappolaGIoDev è una piattaforma SaaS per generare plugin e config di minecraft con l'AI, la piattaforma è open source. ecco alcune sue funzioni:
-home page
-dashboard utente
-panello admin
-generatore plugin di minecraft con l'AI (usa l'API KEY di open router AI openrouter.ai )
-generatore config di minecraft con l'AI (usa l'API KEY di open router AI openrouter.ai )
-pagina prezzi (devi configurare Stripe per i pagamenti stripe.com )
-pagina impostazioni utente (sara aggiunta a breve)
-database (devi configurare SuperBase supabase.com/database )
 




ISTRUZIONI PER L'USO:
1. scarica progetto da GitHub al deskopt del tuo PC
2. estrai la cartella compressa (.zip)
3. apri il terminale digitando cmd nel cerca di windows
4. digita nel terminale: cd C:\Users\<tuonomeutente>\Desktop
ricordati di cambiare <tuonomeutente> con il tuo nome utente windows, il mio per esmpio è gioele.
5. digita nel terminale npm install
6. quando ha finito apri il file .env.local con blocco note o l'editor di testo che hai
7. dentro troverai cose del genere: OPENROUTER_API_KEY=
8. devi sostituire tutti i paramentri vuoti con dati reali, ci sono le istruzioni nel stesso file.
9. riapri il terminale come prima e digita nel terminale nella cartella del progetto npm run dev
10. se è tutto correto dovresti andare all' indirizzo http://localhost:3000/
e quindi sei nella piattaforma (solo tu ci puoi accedere perchè l'hai avviata in locale)
